# Implementation status and audit

The branch was created from local main `a36840a`, which uses the historical `macqwen` package; it is isolated from the newer Veystrix app worktree. `macqwen/cli.py` selects an interpreter and model, `session.py` constructs the backend and owns session behavior, `server.py` renders conversations and serves HTTP, `checkpoints.py` discovers local assets, `backends/base.py` is the shared protocol, and `backends/flashnext.py` coordinates Flash-Next-specific loading, routed experts, cache, prefill, decode and cancellation. The `models/flashnext/` store, pool, prefetcher, prefill, recurrent cache and controller are coupled to Qwen layouts and cannot be substituted for Nemotron without an adapter and tests. `run_agent.py`, API routes, measurement standard, invariants and overnight routing caveat were inspected as starting points; this is not yet a complete dependency audit.

Implemented: fail-closed public config check; bounded, read-only safetensors shard-header/index parser and opt-in per-expert MLX affine tensor index; synthetic MLX hybrid model and greedy runtime; SSD record reader with checksummed bounded host LRU; experimental affine 4-bit streamed expert computation integrated into the tiny hybrid layer; model/token/execution fingerprinted synthetic state snapshot; mathematical memory estimator; a synthetic on-disk checkpoint fixture, a synthetic-only token-level backend adapter, model-free tests, and benchmark matrix generator. Source does not download a checkpoint.

Not implemented: real-weight tensor index and mmap/SSD format, streaming quantized real experts, asynchronous I/O and GPU buffer residency, dense-core loader/offload, a complete `macqwen.backends` adapter, server model registration, compatible model tokenizer and complete Hermes flows, production-grade persisted cache validation, measured memory limits, and MTP. The snapshot code is a prototype: shape, byte-size, identity and corruption handling require an adversarial review before using it with real user data. The streamed reader holds bounded host bytes; the indexed reader bounds logical resident arrays, but lazy MLX graphs and temporary arrays can outlive eviction, so neither enforces a hard GPU memory budget. The indexed reader accepts F32, F16 and BF16 affine scales/biases and its assumed converted per-expert names are not verified against a real converted checkpoint. `--check` validates metadata only and explicitly reports inference unavailable.

Legacy Bonsai-2, K2-Horizon and Qwen27B have NOT been removed: they are imported by the current CLI, session, discovery and shared modules. Removing them without completing the dependency migration would break the working default. Thus the two-model-only requirement and completion criteria remain unmet. Neither this branch nor the public distribution repository has been pushed or merged.
