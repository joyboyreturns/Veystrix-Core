## Veystrix

**Download**: `Veystrix-<version>-arm64.dmg` (drag to Applications) or the `.zip` (used by the in-app updater).
Verify with `shasum -a 256 -c SHA256SUMS.txt`. Requires an Apple-silicon Mac (macOS 26.2 or later, 16 GB unified memory
recommended) and a model checkpoint you supply; **no model is included and none is downloaded**.

Veystrix is proprietary freeware, not open source. See LICENSE and THIRD_PARTY_NOTICES.md in the DMG.
