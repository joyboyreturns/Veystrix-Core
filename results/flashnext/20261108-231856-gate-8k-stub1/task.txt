# NIMBUS GATEWAY project brief
Nimbus is a multi-service backend. This brief summarises each module's behaviour and operational notes. Configuration lives in per-service YAML files under services/<name>/config/; the example files are templates and are not what production loads. Details change between releases, so read the actual file when you need a value.
### services/gateway-v1 (module 0)
The gateway v1 module rate-limits audit events and streams export manifests before handing them to the next stage.
