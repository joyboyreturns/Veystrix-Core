# NIMBUS GATEWAY project brief
Nimbus is a multi-service backend. This brief summarises each module's behaviour and operational notes. Configuration lives in per-service YAML files under services/<name>/config/; the example files are templates and are not what production loads. Details change between releases, so read the actual file when you need a value.
### services/gateway-v1 (module 0)
The gateway v1 module rate-limits audit events and streams export manifests before handing them to the next stage.
- Failure mode 0.0: an expired signing key makes it validates session records twice; the runbook says to check queue depth 861 and alert after 22 minutes.
- Failure mode 0.1: an expired signing key makes it indexes profile snapshots twice; the runbook says to check queue depth 755 and alert after 17 minutes.
- Failure mode 0.2: a clock skew above two seconds makes it deduplicates queue offsets twice; the runbook says to check queue depth 538 and alert after 7 minutes.
Owner rotation 5; dashboards: ops/gateway/628; test target `make test-gateway-1` runs 36 cases.
